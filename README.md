# davidhanenko.com

Personal portfolio — a single Next.js app with content kept in the repo (no CMS, no separate backend).

Currently a placeholder (intro animation + contact links) while the full site is being rebuilt.

## Built with

- Next.js (App Router), React, TypeScript
- Tailwind CSS
- Vercel

## Getting started

```sh
pnpm install
pnpm dev
```

Open http://localhost:3000.

Site copy and media URLs live in `content/site.ts`.
